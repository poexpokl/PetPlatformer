# Структура кода
В каждой папке представлен код для конкретной предметной области.
#### Bosses 
Для боссов или создаваемых ими объектов.
#### Enemies 
Для не являющихся боссами врагов или создаваемых ими объектов.
#### Environment 
Для окружения в локации, арен, а также статичных и интерактивных объектов.
#### Interfaces 
Все скрипты, являющиеся интерфейсами.
#### Player 
Для персонажа и его управления.
#### SaveSystem 
Содержит 2 скрипта, к которым необходимо обращаться при сохранении или загрузке. SaveLoad.cs для обычных случаев, а DisposableSaveLoader для необратимых.
#### UI 
Для логики и поведения UI.
