# Структура кода
Bosses - всё, что касается боссов или создаваемых ими объектов.
Enemies - всё, что касается не являющихся боссами врагов или создаваемых ими объектов.
Environment - всё, что касается окружения в локации, арен, а также статичных и интерактивных объектов.
Interfaces - все скрипты, являющиеся интерфейсами.
Player - всё, что касается игрового персонажа и его управления.
SaveSystem - содержит 2 скрипта, к которым необходимо обращаться при сохранении или загрузке. SaveLoad.cs для обычных случаев, а DisposableSaveLoader для необратимых.
UI - всё, что касается логики и поведения UI.
